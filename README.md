# lunacalendar.github.io

The small public site behind Luna's share and invite links. Its source lives in Luna's own repository under `site/`;
this repository is a copy published by GitHub Pages.

- `.well-known/assetlinks.json` tells Android these links belong to Luna (com.blazeomega.luna and com.ezra.luna.dev), so
  tapping one opens the app directly.
- `event.html` and `join.html` show an "Open in Luna" button for anyone whose phone opens the link in a browser.
- `terms.html` is Luna's terms of use, which people agree to in Luna before adding anything others see.
- `privacy.html` is Luna's privacy policy and `delete-account.html` says how to delete an account, with or without
  the app; Google Play links to both.
